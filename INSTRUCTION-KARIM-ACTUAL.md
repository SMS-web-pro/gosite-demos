# TÂCHE KARIM — Création 24 sites pro

## Mission
Construire les 24 sites professionnels selon le prompt SITE-BUILD-PROMPT.md à la LETTRE.

## Données client
Fichier : `prospects_usa/client_data.json` (24 prospects)

## Prompt SITE-BUILD-PROMPT.md — À SUIVRE À LA LETTRE

### Étape 1 : Données client
- Nom entreprise, téléphone, email, adresse/ville, services, horaires, photos (3-5), avis (3), logo

### Étape 2 : Structure obligatoire (10 sections)
1. Hero — nom + tagline + CTA principal
2. Services — icônes + descriptions
3. À propos — histoire + valeurs
4. Stats — chiffres clés
5. Galerie — photos client
6. Localisation — Google Maps embed
7. Témoignages — avis clients
8. FAQ — 4-5 questions
9. Contact — formulaire + téléphone
10. Footer — coordonnées + liens

### Étape 3 : Design
- Couleurs pros (pas de néon)
- Typographie lisible (system-ui/Georgia)
- Espacement 120px entre sections
- Mobile responsive
- Pas de doublons

### Étape 4 : Images
- placehold.co 1200x800
- Alt text descriptif

### Étape 5 : Animations
- AOS fade-up par section
- Max 3 animations/section
- Pas de JS lourd

### Étape 6 : SEO
- Title unique, meta description, canonical, Schema.org LocalBusiness

## INTERDIT (aucune exception)
- Inventer des données client
- Ajouter des sections non demandées
- Copier-coller d'un autre site
- Lorem ipsum
- Oublier Google Maps

## Livraison
- Code source de chaque site
- URLs Vercel déployées
- Liste des 24 URLs

## Deadline
Avant envoi des emails
