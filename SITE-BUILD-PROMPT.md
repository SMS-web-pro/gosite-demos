# SITE BUILD PROMPT — Professional Demo Site

## Étape 1 : Récupérer les DONNÉES CLIENT
Avant tout, récupérer ces données du client :
- Nom entreprise
- Téléphone
- Email
- Adresse / ville
- Services proposés
- Horaires
- Photos (3-5)
- Avis clients (3)
- Logo

## Étape 2 : Structure obligatoire du site
1. **Hero** — nom entreprise + tagline + CTA principal
2. **Services** — liste des services avec icônes
3. **À propos** — histoire + valeurs
4. **Stats** — chiffres clés (avis, années, clients)
5. **Galerie** — photos client
6. **Localisation** — Google Maps embed
7. **Témoignages** — avis clients
8. **FAQ** — 4-5 questions
9. **Contact** — formulaire + téléphone
10. **Footer** — coordonnées + liens

## Étape 3 : Design
- Couleurs professionnelles (pas de néon)
- Typographie lisible (system-ui ou Georgia)
- Espacement entre sections : 120px minimum
- Mobile responsive obligatoire
- Pas de doublons de contenu

## Étape 4 : Images
- Utiliser placehold.co pour les placeholders
- Dimensions : 1200x800
- Alt text descriptif

## Étape 5 : Animations
- AOS fade-up sur chaque section
- Pas plus de 3 animations par section
- Performance : pas de lourds JS

## Étape 6 : SEO
- Title unique par site
- Meta description
- Canonical URL
- Schema.org LocalBusiness

## INTERDIT
- Ne pas inventer de données client
- Ne pas ajouter de sections non demandées
- Ne pas copier-coller d'un autre site
- Ne pas utiliser de texte générique "lorem ipsum"
- Ne pas oublier le Google Maps
